- **ရက်စွဲ:** 2026-10-27
- **အခြေအနေ:** ✅ ပြီး (2026-10-27) — typecheck / build pass; 360px browser — ပစ္စည်းပြတ်တွင် "ပြတ်" တစ်ကြိမ်သာ, ကျသင့်ငွေ/qty မပြ, "အခြားဆေးများ ကြည့်မယ်" → ယခင် page (direct link ဆိုလျှင် /products); ပစ္စည်းရှိ product ယခင်အတိုင်း (cart ထည့် OK); test DB ဖျက်ပြီး

## ၁. ပြဿနာ
`src/pages/ProductDetail.tsx` တွင် ပစ္စည်းပြတ်ကြောင်း **၃ နေရာ** ပြနေ:
| # | နေရာ | စာသား |
|---|---|---|
| 1 | Product code (`FM202`) ဘေး badge (line ~163) | ပစ္စည်းပြတ်နေပါသည် |
| 2 | နာမည်အောက် အနီ banner (line ~174) | ပစ္စည်းလက်ကျန် ပြတ်နေပါသည် |
| 3 | အောက်ခြေ ခလုတ် (line ~336) | ပစ္စည်းပြတ်နေပါသည် |

ထို့အပြင် အောက်ခြေ bar တွင် ဝယ်မရသော်လည်း "ကျသင့်ငွေ စုစုပေါင်း 90,000" နှင့် qty − 1 + ကို ဆက်ပြနေ၍ ရှုပ်

## ၂. ပြင်ပုံ — **တစ်နေရာတည်း** (banner) တွင်သာ ပြ
```
┌───────────────────────────────┐
│ [FM202]                       │  ← badge ဖယ် (code သာ)
│ Alfalfa(O)အယ်လ်ဖာဖာအားဆေး      │
│ ┌───────────────────────────┐ │
│ │ ⊘ ပစ္စည်းလက်ကျန် ပြတ်နေပါသည်  │ │  ← တစ်ခုတည်းသော အချက်ပြ (icon ထည့်)
│ │   ပစ္စည်းပြန်ရောက်လျှင် ဝယ်ယူနိုင်ပါမည် │ │  ← ဘာလုပ်ရမလဲ ရှင်းပြ
│ └───────────────────────────┘ │
│ အမှတ်တံဆိပ် / အမျိုးအစား / ဓာတုအမည် (မပြောင်း) │
└───────────────────────────────┘
 ဈေးနှုန်း (ပုံး 90,000 / ဖာ 1,080,000) — ကြည့်ရန် ဆက်ပြ (မပြောင်း)

 အောက်ခြေ bar (ပစ္စည်းပြတ်သောအခါသာ):
┌───────────────────────────────┐
│ [   အခြားဆေးများ ကြည့်မယ်   ]  │  ← ကျသင့်ငွေ + qty stepper ဖယ်; ယခင် page သို့ ပြန်
└───────────────────────────────┘
```
| အပိုင်း | ပြောင်းလဲမှု |
|---|---|
| Code ဘေး badge | **ဖယ်** |
| အနီ banner | ဆက်ထား + `XCircle` icon + ရှင်းပြစာ တစ်ကြောင်း |
| အောက်ခြေ bar | ပစ္စည်းပြတ်လျှင် ကျသင့်ငွေ / qty stepper / disabled ခလုတ် **မပြ**; outline ခလုတ် "အခြားဆေးများ ကြည့်မယ်" တစ်ခုသာ (`navigate(-1)`; history မရှိလျှင် `/products`) |
| ပစ္စည်းရှိသော product | **မပြောင်း** |
